# 국지 4그룹 초안 연계 문제 — 쪽·문장 근거와 보완 제시 (2026-11-13, 초안 원본 재확인)
최종안이 오면 마지막 열에 "최종안 ○쪽 ○항: 어떻게 반영" 또는 **없음**을 채운다. 강평서·분석자료에 그대로 옮긴다.
- 1조 쪽 표기: 초안 하단 쪽 번호 그대로(위기평가 n/6, 대응방향 n/4, 대응방책 n/6).
- 2조 쪽 표기: 초안에 쪽 번호가 없어 제출 순서로 센다. p1 상황개요 / p2 전략상황 / p3 군사상황 / p4 종합평가·대응방향 / p5 판단근거 / p6 방책(임무·최종상태·작전개념 가) / p7 작전개념 나~다·과업(공통·합참·지작사) / p8 과업(해작사~국심단)·협조지시 / p9 합동화력 대상표적·선정사유 / p10 타격수단.
