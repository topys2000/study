# 국지 과목 실습 진행 절차 (1그룹 산출물 기준 템플릿)

과제: 요구사항 #1 · 실습상황 #2 「합동국지도발대비작전」 위기조치 실습 (실습 3시간 + 토의 2시간)
1그룹 자료: `국지/1그룹/` (실습안내서_핵심본, 교관강평_1·2조반영(초안), 교관강평_최종(1·2조), 학생최종안_사진/). 산출물은 .hwpx로 제공

## Step1. 교관 지도안 분석 (입력자료)
- 실습상황 #0(주변국 안보정세)·#1(북한 정세)·#2(NSC 지침, 합참의장 작전지침), 교관 지도중점.
- 지도중점 핵심: 위기평가에서는 **필요성**, 방책발전에서는 **비례성**. 작계에 갇히지 않기, 무기 고르기 금지, 최종상태 = 위기 이전 회복, 북한 역대응 고려, 중심은 군사방책(DIE 과다 금지), 한·미 협의절차는 토의 제외.

## Step2. 학생 실습안내서 (학생장교 배포용, 고정 구성)
- 헤더: 요망수준 / 나의 임무(합참 위기조치반장=작전본부장) / 산출물(합참의장 보고용 「위기평가판단서」: 위기평가 + 단일 대응방책) / 참고자료 / 나의 관점(부대 자위권이 아닌 국가 자위권·합참 차원)
1. 가장 중요한 원칙: 분석과 대응은 하나의 사슬 (①상황개요 → ②상황평가 → ③종합평가 → ④대응방향 → ⑤작전목적·최종상태·목표 → ⑥임무·실시, 단계별 연결 질문) + 연계 끊김/연계 예시 표
2. 단계별 핵심: 위기평가 / 방책발전 (2항 임무·3항 실시 집중, 비례성 정의, 합동작전으로 작성)
3. 꼭 기억할 다섯 가지
4. 진행 계획 (안내10 → 위기평가110 → 방책발전60 → 발표·토의90 → 강평30분)
5. 제출 전 점검표 (연계성 중심 7항목)
6. 작성 양식① 위기평가 (①~④)
7. 작성 양식② 대응방책 + **연계 확인란**(근거가 된 평가 항목)

## Step3. 학생 실습지(초안) 분석
- 조별 위기평가판단서를 받아 위 양식 기준으로 분석: 핵심 판단, 대응 목표, 작전개념, "지금 타격하는가", 돋보이는 점, 가까운 역사 사례.
- 연계 점검표: 분석에서 쓴 말 → 방책에서의 답 → ○/△/✕ 강평.

## Step4. 교관 강평서 (교관용, 학생 배포 금지, 강평 15분 기준)
- 강평의 핵심 메시지 3개 (결론이 아니라 연계가 기준 / 조별 선택을 역사적 사례에 대응 / 분석에서 쓴 말은 방책이 책임)
- 강평 순서: 총평·비교3 → 조별 강평 4·4 → 과거 사례 2 → 종합 질문·마무리 2분
1. 조별 한눈에 비교표
2~3. 조별 강평: 잘한 점 / 연계 점검(끊긴 고리 표) / 보완할 점 / 강평 멘트 예시
4. 과거 사례로 비춰보기 (판문점 1976, 연평도 2010, 천안함·목함지뢰)
5. 종합토의 질문 3개 + 유도 방향
6. 마무리 멘트
- 부록: 과거 사례 상세(경과·대응·결과·교훈·멘트), 정세평가 착안(후계 구도는 "가설"로 지도). 비공식 일화는 "전해지는 이야기"로 표기.
