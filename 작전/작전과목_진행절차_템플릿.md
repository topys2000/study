## Job1. 논문 2편 선정 + 요약해설본
- 선정 기준: 동일 주제, 상반된(또는 보완적 대립) 관점, 최근 논문. 1그룹은 국내 군 학술지 1편 + 해외 싱크탱크 1편 조합.
- 해외 논문은 한국어 번역본도 함께 제공.
- 요약해설본(각 3쪽 내외) 고정 구성:
  1. 헤더: 서지, "○소조 발표 준비용 길잡이 (원문 대체 아님)", 한 줄 요약 박스
  2. 저자 / 작성 시점(정보 기준 시점의 한계) / 분량·구성
  3. 전체 구조 한눈에 보기 (장별 원문 쪽수)
  4. 장별 요약 (표, 원문 쪽수 표기)
  5. 주요 용어 정리
  6. 합동 6대 기능과 연결하기 (기능별 시사점 + 원문 위치) — 발표 3·4 준비용
  7. 비판적으로 읽을 점 (질의 대비) — 마지막 항목은 상대 논문과의 관계
  8. 각주: 학습 보조자료, 인용 시 원문 쪽수 확인

## Job2. 실습안내서·발표양식 (4쪽)
- 운영 원칙: 전원 두 논문 숙독, 소조별 발표조 4 + 질의조 4, 교차 구조(1소조 질의조 ↔ 2소조 발표).
- 발표조: 발표1 논문분석(5분) / 발표2 북한군이 얻었을 교훈 — 전략·작전·전술(5분) / 발표3 지휘통제·정보·화력(4분) / 발표4 이동및기동·방호·지속지원 + 우선과제 3개(6분).
- 질의조: 질의1 논문해석 검증 / 질의2 북한군 교훈 검증 / 질의3 대응Ⅰ / 질의4 대응Ⅱ+종합.
- 진행 120분: 오프닝(HyperFrames 영상) 5 → 1소조 발표 20 → 질의Ⅰ 20 → 휴식 5 → 2소조 발표 20 → 질의Ⅱ 20 → 종합토의 20 → 강평 10.
- 양식: 발표 양식(Ⅰ논문분석 Ⅱ북한군 교훈 Ⅲ6대 기능 표 Ⅳ결론), 질의 양식(질의·근거·응답평가), 작성 샘플 1~2개, 평가 기준(발표 25/25/30/20, 질의 40/40/20).
- 북한군 교훈: "관찰자"와 "참전자"(쿠르스크 파병, 공개 보도 수준) 교훈 구분.

## Job3. 교관 강평자료 (실제 발표 반영, 학생 배포 금지, 5쪽)
1. 강평 핵심 메시지 3개 (10분 기준)
2. 강평 진행 순서 (총평1·소조별 2·2·종합3·마무리2분)
3. 소조별 강평: 잘한 점 / 보완할 점(관찰-강평포인트 표) / 강평 멘트 예시
4. 종합 교훈: 두 소조 결론 통합 + 6대 기능 비교표(교관 코멘트)
5. 종합토의용 추가 질문 3개 + 유도 방향
6. 북한군 교훈 강평 (관찰자/참전자, 과대·과소평가 점검)
7. 마무리 멘트
8. 우수 포인트 선정 (분석·대응방향·연결·질의응답)
- 입력 필요: 각 소조의 실제 발표자료(양식 작성본).
